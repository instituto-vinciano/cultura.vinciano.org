# Paraíba ponto Cultural — home pronta para alimentação

Nesta versão, a página inicial já pode ser alimentada sem editar o HTML.

Você trabalha principalmente com:
- `dados/home.js` para textos, categorias, datas e links;
- `assets/home/` para as 7 imagens fixas da página inicial.

Arquivos de imagem da home:
- manchete
- destaque-01
- destaque-02
- pauta-01
- pauta-02
- pauta-03
- pauta-04

Veja `TAMANHOS-IMAGENS-HOME.txt` para proporções e tamanhos recomendados.

As páginas individuais das matérias continuam separadas em `materias/` e podem ser
trabalhadas depois, sem impedir que a home seja concluída agora.


## Padrão das imagens da home
As sete posições visuais foram padronizadas definitivamente em `.jpg`.
Basta substituir o arquivo correspondente em `assets/home/` mantendo o nome.
